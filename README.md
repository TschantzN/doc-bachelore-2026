# Documentation - Travail de Bachelor 2026

**Sujet :** Transmission vidéo basse latence pour drone FPV via Wi-Fi HaLow (802.11ah)  
**Auteur :** Nathan Tschantz  
**Orientation :** Systèmes informatiques embarqués (HEIG-VD)  

---

## Structure du dépôt

* **`RAPPORT/`** : Sources LaTeX du rapport principal et des annexes.
* **`CODES/`** : Codes sources applicatifs Firmware STM32, Gateway C sur RPi, scripts de mesure glass-to-glass.
* **`CAHIER_DES_CHARGES/`** : Cahier des charges du projet.
* **`JOURNAL/`** : Notes journalières, journal de travail et diagrammes de Gantt de suivi de projet.
* **`SCRIPT_MESURE/`** : Scripts Python pour plotter la moyenne des mesures de latence.
* **`MM8108-EKH05/`** : documentation de base du module EKH05.
* **`MM8108-EKH19/`** : documentation de base du module EKH19.
* **`TB_INFO/`** : Informations administratives et consignes liées au travail de Bachelor.
